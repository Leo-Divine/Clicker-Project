# Crystal Clicker
I created this game as the passion project for sophomore year. Spent $50 on sprites for a game I didn't even finish.

With showcase in mind, all of the games different upgradables are stored in JSON files in ./json/. You can change all of the content of the game from there.

## How to set up the game
1. Copy the code on your local device.
2. Using an IDE (Use VSCode I promise you it will help you and me), open the project directory on there.
3. (Assuming you're using VS Code) Go to extensions and install "Live Server". This will let you have a server that you can host the html file from.
4. Once installed, there should be a live server button on the bottom of the window. Click that to start the live server. It should give you a link that the game can run from.

### If you plan on showing the code and letting kids change it:
- DELETE THE .git FOLDER FROM THE DIRECTORY!
- Make sure to create backups of the code so that if you can't fix the changes made, you can reset quickly.
- For this game specifically, try to only let the kids change the json. It should hopefully save you some headaches.
